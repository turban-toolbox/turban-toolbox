# Turbulence Analysis Toolbox (Turban-Toolbox)

Welcome to TURBAN. You can find documentation on [readthedocs](https://turban-toolbox.readthedocs.io/en/latest/).
The git repository is hosted on [github](https://github.com/turban-toolbox/turban-toolbox).


Shear processing (dissipation rate of turbulent kinetic energy) is fully functional. Microtemperature processing (dissipation rate of temperature variance, chi) gives not too unreasonable results but is still experimental. More is on the way (e.g. high-frequency ADCP).
